# Vibecodescribe

A community platform for AI-assisted coders to share projects, get feedback, and connect. Built for the AgnesCode Build Challenge.

## Features

- **Magnetic Cursor Trail** - Interactive cursor that follows your mouse movement smoothly
- **Light/Dark Mode** - Toggle between themes with persistence
- **Community Tribes** - Browse and join interest-based groups
- **Project Feed** - Share and discover projects from other creators
- **Engagement** - Like and interact with posts
- **Mobile Ready** - Responsive design works on all devices

## Tech Stack

- **React 18** with Vite for fast development
- **Tailwind CSS** for styling
- **React Router** for navigation
- **Vercel** for deployment

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Deployment

This project is configured for automatic deployment to Vercel. Push to the `main` branch and Vercel will build and deploy automatically.

Live URL: https://vibecodescribe.vercel.app

## Project Structure

```
src/

```
